# Text Diff Checker

[Live Demo](https://DamianKuras.github.io/text-diff-checker)

A lightweight, browser‑based tool for comparing two blocks of text side‑by‑side, with color‑coded diff output powered by [jsdiff](https://www.npmjs.com/package/diff).

## Features
- **Color‑coded changes** – green for additions, red for deletions
- **Responsive layout** 

## Installation
Clone the repo and install dependencies:
```bash
git clone https://github.com/DamianKuras/text-diff-checker.git
cd text-diff-checker
npm install
```

## Development and build
### Start dev server
```bash
npm run start
```
## Build for production
```bash
npm run build
```
Outputs to dist folder.
